# Python Market-Making Simulator

An early-stage personal Python project exploring how market-making
strategies behave in a simulated limit order book.

## Planned functionality

- Submit and cancel limit orders.
- Execute market orders against available liquidity.
- Match orders using price-time priority.
- Handle partial fills.
- Track cash, inventory, trading fees and profit/loss.
- Generate reproducible synthetic order flow.
- Compare a fixed-spread market maker with an inventory-aware strategy.

## Research question

How does adjusting bid and ask quotes in response to inventory affect
profitability and inventory risk under different market conditions?

## Development milestones

1. Implement order handling and the matching engine.
2. Verify matching behaviour and cash/inventory accounting.
3. Add synthetic market participants and reproducible simulations.
4. Implement and compare two market-making strategies.
5. Produce charts and document assumptions and limitations.

## Project boundaries

This is an independent personal project using synthetic data.
It will not use BSIC code, university-owned work, personal data,
broker connections, or real-money trading.

## Current status

Planning and initial setup. Implementation has not started.
